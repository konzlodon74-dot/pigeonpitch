## How it works

`main.py` holds the pitch line as a constant, asserts it is non-blank, a single line, and 1–200 characters, then writes it as UTF-8 bytes with no trailing newline to `/output/entry.txt`.

## Run

```sh
python3 main.py
cat /output/entry.txt
```
